
# 🚢 Warships — консольная и GUI версия морского боя

Это учебный проект, где логика игры полностью отделена от интерфейса.
Есть три независимые части:

* **main** — чистая игровая логика, не зависит от Qt
* **cli** — консольная версия игры
* **gui** — Qt6 версия игры с графическим интерфейсом

Главная идея — один движок (core), несколько оболочек (CLI/GUI).

    # Warships — локальная / сетевая реализация "Морской бой" (Qt GUI)

    Это проект — простая реализация игры "Морской бой" с графическим интерфейсом на Qt6.
    README описывает текущую реализацию в этом репозитории: как собирать, запускать и основные особенности игрового процесса.

    Ключевые особенности
    - Набор кораблей фиксирован: 1 корабль длины 4, 2 корабля длины 3, 3 корабля длины 2 (всего 6).
    - Расстановка кораблей осуществляется перетаскиванием (drag & drop) в окне `DragDropWindow`.
    - Нельзя размещать корабли вплотную — запрет на соседние клетки (включая диагонали).
    - Модели кораблей становятся недоступными после размещения (нельзя поставить одну модель дважды).
    - Автоподтверждение: окно расстановки автоматически закрывается, как только размещён последний требуемый корабль.
    - Игровой цикл выполняется в отдельном рабочем потоке; обновления GUI идут через queued-вызовы (`QMetaObject::invokeMethod`).
    - В центре окна отображаются имена игроков, под ней — статус: "твой ход" / "подожди-подожди".
    - В правом поле можно кликать только в свой ход — клик отправляет выстрел.
    - Кнопка "Get Lose" позволяет сдаться и оповестить оппонента.

    Зависимости
    - Компилятор C++ с поддержкой C++20 (g++ или clang).
    - CMake (рекомендуется >= 3.16) и генератор (например, Ninja).
    - Qt6 (модули Widgets, Core, Gui).

    Пример для Debian/Ubuntu (указывает набор пакетов, может отличаться в разных дистрибутивах):

    ```sh
    sudo apt update
    sudo apt install build-essential cmake ninja-build qt6-base-dev qt6-tools-dev libqt6core6-dev libqt6widgets6-dev
    ```

    Сборка
    -------
    Из корня репозитория выполните:

    ```sh
    cmake -S . -B build -G Ninja
    cmake --build build --config Debug
    ```

    После сборки исполняемый файл будет находиться по пути `build/appwarships`.

    Запуск и соединение
    -------------------
    При запуске `./build/appwarships [порт]` приложение прочитает в консоли ваше имя и invite-код (invite можно оставить пустым — тогда приложение попытается выступить хостом на loopback).

    Пример локальной игры на одной машине (два процесса):
    1. В одном терминале запустите `./build/appwarships` и оставьте поле invite пустым — программа станет хостом и при ожидании соединения напечатает invite-код в консоль.
    2. Во втором терминале запустите `./build/appwarships` и введите invite-код, который показал хост, — программы соединятся.

    Параметр `порт` можно указать, если нужно использовать нестандартный порт (по умолчанию в коде — 5555).

    Управление (GUI)
    - Перетаскивайте корабли из правой панели на левое поле; перед броском нажмите `R` для поворота (горизонтально/вертикально).
    - Нельзя размещать корабли поверх других или в соседних клетках — в превью будет показан недопустимый вариант.
    - После успешной расстановки всех требуемых кораблей окно закроется автоматически и начнётся игра.
    - В вашем ходу правое поле становится кликабельным; клик по клетке отправляет выстрел через сеть.
    - Центральная метка (`midLabel`) показывает имена игроков; под ней добавлен `statusLabel`, отображающий "твой ход" или "подожди-подожди".

    Структура кода (где смотреть)
    - GUI: `src/gui/window.h` / `src/gui/window.cpp` — `GameWindow`, `DragDropWindow`, `WinWindow`.
    - Основная логика: `src/warship.cpp` — игровой цикл, синхронизация кликов, взаимодействие с туннелем.
    - Сетевой туннель: `src/tunnel.cpp`.
    - Поле и корабли: `src/for_warship.cpp`.

    Поведенческие детали и примечания
    - Логика игры выполняется в отдельном потоке; исключения `EndGame` прокидываются обратно в основной поток через `std::promise`/`std::future` и затем обрабатываются в `main()` (показывается окно победителя `WinWindow`).
    - GUI и консоль смешаны: при запуске программа запрашивает имя и invite в консоли, далее открываются окна Qt.
    - Проверка размещения кораблей основана на CSS-стиле кнопок (цвет `#444`) — если будете менять стили, имейте это в виду.

    Отладка
    - Если сборка падает с ошибками на Qt/MOC — убедитесь, что Qt6 dev-пакеты установлены и доступны CMake.
    - Если игра зависает при ожидании сети — проверьте, что порт открыт/доступен и оба клиента используют одинаковый порт.

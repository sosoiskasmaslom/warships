Warships — Морской бой (GUI)
=================================

Кратко
------
Небольшая реализация игры в морской бой с графическим интерфейсом на Qt6. Поддерживается расстановка кораблей перетаскиванием (drag & drop) и пошаговая сетевая игра через простой туннель.

Возможности
-----------
- Расстановка кораблей перетаскиванием в GUI.
- Фиксированный набор кораблей: 1×4, 2×3, 3×2 (всего 6 кораблей). Расстановка валидируется автоматически.
- Корабли не могут располагаться вплотную друг к другу, включая по диагонали.
- После размещения модель корабля становится недоступной (нельзя поставить ту же модель дважды).
- Как только поставлен последний корабль, расстановка автоматически подтверждается и игра продолжается.
- Поочередные ходы: на своём ходе вы можете нажать клетку правого поля, чтобы выстрелить.
- Под центральной надписью отображается статус: "твой ход" или "подожди-подожди".
- Кнопка «Get Lose» позволяет сдаться; оппонент получит уведомление.
- Сетевая игра реализована через простой протокол туннеля (invite code / порт).

Зависимости
-----------
- Компилятор C++ с поддержкой C++20 (g++ / clang++)
- CMake (рекомендуемая версия >= 3.16)
- Ninja (рекомендуется) или другой подходящий генератор для CMake
- Qt6 (модули Widgets, Core, Gui и инструменты разработки)

Пример установки на Debian/Ubuntu:

```sh
sudo apt update
sudo apt install build-essential cmake ninja-build qt6-base-dev qt6-tools-dev libqt6core6-dev libqt6widgets6-dev
```

Сборка
------
Из корня репозитория выполните:

```sh
# создание каталога сборки и конфигурация
cmake -S . -B build -G Ninja
# сборка
cmake --build build --config Debug
```

В результате будет создан исполняемый файл `build/appwarships`.

Запуск
------
Пример:

```sh
./build/appwarships [порт]
```

- Параметр `порт` (опционально) — порт, используемый туннелем (по умолчанию в коде: 5555).

При запуске программа попросит ввести имя игрока и invite-код (если хотите подключиться к другому хосту). Если поле invite оставить пустым, приложение может выступить в роли хоста и вывести invite-код, который нужно передать оппоненту.

Управление (GUI)
----------------
- Перетаскивайте модели кораблей из правой панели на левое поле 10×10.
- Нажмите `R`, чтобы переключить ориентацию модели перед постановкой.
- Размещение, нарушающее правило вплотной посадки или перекрывающее другие корабли, отклоняется.
- После установки последнего корабля расстановка подтверждается автоматически.
- На вашем ходе правое поле становится кликабельным — клик по клетке выполняет выстрел.
- Центральный текст показывает имена игроков; под ним — статус хода.
- Кнопка «Get Lose» сдаёт игру и оповещает соперника.

Реализация (основные файлы)
---------------------------
- GUI: `src/gui/window.*` (классы `GameWindow`, `DragDropWindow`, `WinWindow`).
- Логика игры / сеть: `src/warship.cpp`, `src/tunnel.cpp`, `headers/warship.h`.
- Примитивы поля/кораблей: `src/for_warship.cpp`.

Особенности реализации
----------------------
- Основной игровой цикл выполняется в рабочем потоке; обновления GUI выполняются через queued-вызовы `QMetaObject::invokeMethod`.
- Расстановка на стороне GUI помечает занятые клетки стилем `#444`; остальные части кода ориентируются на этот маркер при извлечении размещённых кораблей.

Отладка и советы
---------------
- Если сборка жалуется на отсутствие заголовков Qt или moc-файлов — убедитесь, что установлены пакеты разработки Qt6 и CMake их находит.
- Если приложение зависает на сетевых операциях, проверьте доступность порта и отсутствие блокировки фаерволом.

Контакты / примечания
---------------------
Репозиторий комбинирует взаимодействие через GUI и консоль; некоторые сообщения всё ещё выводятся в консоль. По желанию могу добавить небольшое окно-лаунчер для ввода имени и invite-кода перед запуском игры.
